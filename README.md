# AlgoLens - Interactive Sorting Visualizer

A lightweight web application to visualize common sorting algorithms in real time. Built using plain **HTML**, **CSS**, and **vanilla JavaScript**.

---

## 🚀 Features

### 📊 Visual Algorithms: Real-time step-by-step execution for:

- **Bubble Sort**
- **Selection Sort**
- **Insertion Sort**
- **Quick Sort**
- **Merge Sort**

### Custom Controls:
- Adjust array size and execution speed on the fly.
- Input custom numbers to sort specific array configurations.
- Play, pause, and step through iterations manually.
- Metrics Tracker: Live updates for comparisons, swaps, and execution time.
- Reference Code: View the implementation logic alongside time and space complexity details for each algorithm.

- No build tools or package managers required.
- Clone or download the repository.
